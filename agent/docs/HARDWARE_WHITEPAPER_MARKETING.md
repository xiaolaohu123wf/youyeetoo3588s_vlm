## 1. 产品定位

小揽是一款面向**私有化部署**的边缘多模态交互终端：在同一台设备上完成**听、说、看、答**，无需依赖公网大模型即可实现流畅的中文对话与**实时视觉理解**，适合对**数据安全、响应速度、现场稳定性**要求高的客户场景。

我们采用**主控 + 独立 AI 加速**的双层硬件架构，将「实时音视频交互」与「大模型推理」分层处理，既保证麦克风、扬声器、屏幕与网络摄像头的**低延迟联动**，又为视觉语言理解保留**充足的专用算力**，避免单芯片方案常见的「一推理就卡顿、一对话就掉帧」体验问题。

## 2. 核心硬件能力（对外表述）

### 2.1 边缘算力

| 能力维度 | 宣传要点 |
|----------|----------|
| **异构双芯** | 高性能应用处理器 + **独立神经网络加速单元**，专为大模型与多模态推理优化 |
| **端侧大模型** | 多模态视觉语言模型**完整运行于本地**，对话与「看图说话」数据不出域 |
| **推理体验** | 语音首响可达**秒级以内**；视觉理解链路经工程优化，**显著优于**传统「每次重新加载模型」方案 |
| **视频处理** | **硬件级**视频解码能力，支持主流 IPC 网络摄像机协议，长时间拉流稳定 |
| **语音全链路** | 端侧语音活动检测、流式识别与高质量中文合成，**全时监听**与**随时打断** |

> 说明：具体芯片型号、内存容量、PCIe 规格等属于供应链与交付细节，**不在本宣传册范围**；商务与定制项目另行提供《技术对接说明》。

### 2.2 接口与扩展（概念层）

| 类型 | 能力描述 |
|------|----------|
| **网络** | 千兆以太网，适配机房/展厅有线组网；支持局域网内手机、平板、PC **浏览器即开即用**控制台 |
| **调试与运维** | 支持 USB 直连维护通道，便于现场快速部署与恢复 |
| **人机交互** | 麦克风与扬声器方案可适配板载或外置音频；**大屏 HDMI** 全屏展示品牌控制台 |
| **视频输入** | 以**专业级网络摄像机**为主；兼容 RTSP 等主流取流方式，支持**不停机切换**监控画面 |
| **开放接口** | 提供 WebSocket 状态与控制能力，便于与客户既有大屏、中控系统二次集成 |

## 3. 成像与「看得懂」

### 3.1 相机与感光

小揽推荐搭配**高灵敏度、大靶面 CMOS** 的网络摄像机方案（工程上采用**行业主流 800 万像素级、低照度优化**感光平台），在典型室内展厅与办公环境下可获得**清晰、稳定**的画面源。

| 客户感知价值 | 说明 |
|--------------|------|
| **看得清** | 支持高分辨率成像能力，远近景、桌面物品、人物动作均可作为理解输入 |
| **连得稳** | 取流链路支持抗丢包传输策略，减少花屏与断流对体验的影响 |
| **问得快** | 后台持续维护「场景理解」与帧缓存策略，常见「桌面上有什么」「我在做什么」类问题可**近乎即时**语音作答 |

### 3.2 视觉智能闭环

```
网络摄像机 → 边缘视频接入与优化 → 本地多模态大模型 → 自然语言回答 → 语音播报
                    ↑
              Web 控制台实时画面与状态（免插件浏览器访问）
```

| 模块 | 客户可感知的价值 |

| **快速恢复** | 提供面向演示环境的**一键恢复工具包**，缩短展会断电、误操作后的复位时间 |

## 5. 典型应用场景

1. **品牌科技展厅**：访客自然语言提问 + 指向桌面/产品，小揽**看图即答**并语音讲解。  
2. **智慧前台 / 政务引导**：大屏展示 + 语音咨询，降低人力峰值压力。  
3. **智慧办公助理**：会议室外围设备状态、工位环境**可见即可问**（需客户网络与相机部署配合）。  
4. **教育与创新 Lab**：展示「端侧 AI + 多模态」的完整闭环，强调**低延迟与数据本地**。

## 6. 体验指标（宣传口径）

以下为**典型优化环境下**可向客户传达的体验目标，实际数值受现场网络、相机、声学环境影响：

| 体验项 | 宣传表述 |
|--------|----------|
| 语音识别 | **百毫秒级**流式识别，边说边出字 |
| 对话首响 | **数秒内**听到首句回复（复杂问题略长） |
| 视觉问答 | 常见桌面/场景类问题**约 1 秒量级**获得语音反馈（含场景缓存策略时更快） |
| 打断播报 | 用户开口或一键打断，**瞬间**停止播报并重新聆听 |
| 换摄像头地址 | 控制台修改取流地址，**无需重启整机服务** |

## 7. 与「云端方案」的差异化话术

| 对比维度 | 小揽边缘方案 |
|----------|--------------|
| 数据路径 | 视觉与对话**优先本地闭环**，降低音视频上云合规压力 |
| 时延 | 省却公网往返，交互**更跟手** |
| 稳定性 | 弱外网环境下仍可演示核心能力 |
| 成本可控 | 试点阶段流量与 API 调用成本**可预期** |
