# 小揽硬件能力简介（约千字 · 可直接粘贴 Word）

---

**小揽边缘多模态智能交互终端**面向展厅、政务大厅、智慧办公与品牌演示等场景，在一台设备上完成「听、说、看、答」的完整闭环。产品强调**数据不出域、响应跟手、部署可控**：语音对话与视觉理解优先在客户局域网内完成，无需把实时音视频长期送往公网大模型，更适合对隐私与稳定性敏感的行业客户。

硬件上，小揽采用**主控处理器与独立 AI 加速单元**协同的异构架构。主控侧负责麦克风、扬声器、浏览器控制台、网络摄像机取流以及视频硬件解码等实时任务；加速侧专责多模态大模型的本地推理，使「一边流畅对话、一边理解画面」成为可交付体验，而不是实验室里的单次演示。这种分工避免了单芯片方案里常见的资源争抢：用户一提问，画面就卡住；或者一拉高清流，语音就断续。

视频接入以**专业网络摄像机**为主，推荐搭配高灵敏度、大靶面、低照度表现优秀的 CMOS 成像方案，在典型室内光线下提供稳定、清晰的监控级画面。系统支持主流 RTSP 取流，并针对丢包环境做了传输与链路优化，减少花屏、断流对演示效果的破坏。工程上对视觉问答路径做了**低时延优化**：后台持续维护场景理解与帧缓存，当观众问「桌面上有什么」「我在做什么」时，往往能在**约一秒量级**得到自然的中文语音回答；控制台还可**不停机切换**摄像机地址，适应多机位展厅。

语音能力覆盖**全时聆听、流式识别、高质量中文合成**与**播报打断**。用户说话后，识别结果快速上屏；系统生成回复的同时即可开始分句播报，首句反馈通常在**数秒以内**（复杂问题略长）。播放过程中用户再次开口或点击打断，播报可迅速停止并回到聆听状态，互动节奏接近真人对话。Web 控制台通过浏览器即可访问，展示实时画面、对话流、快捷指令与链路延时概览，也可驱动 HDMI 大屏做科技风全屏展示，便于来宾无需培训即可体验。

与纯云端交互相比，小揽的差异化在于：**弱外网环境仍可演示核心能力**；试点阶段的 API 与流量成本更可控；音视频数据路径更短，时延与合规讨论空间更友好。标准交付包括边缘主机软件栈、部署与恢复工具、演示验收清单；摄像机、大屏与麦克风可由集成商按现场选配。具体芯片型号、内部接口与模型资产属于交付细节，不在宣传材料中披露；投标与验收以双方签署的规格书与测试用例为准。
