1. 产品定位

小揽是一款面向私有化部署的边缘多模态交互终端：在同一台设备上完成听、说、看、答，无需依赖公网大模型即可实现流畅的中文对话与实时视觉理解，适合对数据安全、响应速度、现场稳定性要求高的客户场景。

我们采用主控 + 独立 AI 加速的双层硬件架构，将「实时音视频交互」与「大模型推理」分层处理，既保证麦克风、扬声器、屏幕与网络摄像头的低延迟联动，又为视觉语言理解保留充足的专用算力，避免单芯片方案常见的「一推理就卡顿、一对话就掉帧」体验问题。

2. 核心硬件能力

2.1 边缘算力

能力维度宣传要点
异构双芯高性能应用处理器 + 独立神经网络加速单元，专为大模型与多模态推理优化
端侧大模型多模态视觉语言模型完整运行于本地，对话与「看图说话」数据不出域
推理体验语音首响可达秒级以内；视觉理解链路经工程优化，显著优于传统「每次重新加载模型」方案
视频处理硬件级视频解码能力，支持主流 IPC 网络摄像机协议，长时间拉流稳定
语音全链路端侧语音活动检测、流式识别与高质量中文合成，全时监听与随时打断
具体芯片型号、内存容量、内部互连规格等属于供应链与交付细节，不在本宣传册范围；商务与定制项目另行提供《技术对接说明》。

3. 成像与「看得懂」

小揽推荐搭配高灵敏度、大靶面 CMOS 的网络摄像机（800 万像素级、低照度优化感光平台），在典型室内环境下可获得清晰、稳定的画面源。

客户感知价值说明
看得清高分辨率成像，远近景、桌面物品、人物动作均可作为理解输入
连得稳抗丢包传输策略，减少花屏与断流
问得快场景理解与帧缓存策略，常见提问可近乎即时语音作答
网络摄像机 → 边缘视频接入与优化 → 本地多模态大模型 → 自然语言回答 → 语音播报
                    ↑
              Web 控制台实时画面与状态（免插件浏览器访问）

5. 典型应用场景

  1. 品牌科技展厅：访客自然语言提问 + 指向桌面/产品，小揽看图即答并语音讲解。
  2. 智慧前台 / 政务引导：大屏展示 + 语音咨询，降低人力峰值压力。
  3. 智慧办公助理：工位环境可见即可问（需网络与相机部署配合）。
  4. 教育与创新 Lab：展示端侧 AI 多模态闭环，强调低延迟与数据本地。
